02 / EMBLEMFORGE

天堂盟徽製造機

Windows 免費下載

把盟徽設計圖，做成遊戲能用的 24×18 盟徽。

  • 一張圖排多款，自動切格、選號，批次輸出
  • 去背、調色、特效，並預覽遊戲畫面效果
  • 免費使用；圖片只在你的電腦上處理，不會上傳
Windows 10 / 11v0.1.45免費使用

下載後請先「完整解壓縮」再執行 EmblemForge.exe（不要在壓縮檔內直接開）。程式尚未做程式碼簽章，第一次執行 Windows 可能顯示「未簽章」警告；建議先核對下載檔的 SHA-256，確認一致再執行。第一次開啟要等幾秒，畫面可能先黑一下，不是壞了。

下載 v0.1.45（Windows，66.7 MB） ↓詢問使用方式

SHA-256：6EEC8D3AF5D20B7BA7788407DA333085A16DAC262F4A463DEB418166DDF76600
在 PowerShell 執行：Get-FileHash 下載的檔案.zip -Algorithm SHA256，結果應與上面相同。

本程式只處理你的圖片，不會操作或連線遊戲。

03 / LINEAGE TOOLBOX

天堂經典工具箱

Windows 完整安裝版非侵入式插件

把遊戲提醒與查詢，集中在同一個工具。

  • 狀態與技能提醒、語音播報
  • 製作配方與材料查詢
  • 本機保存個人設定
Windowsv0.14.0既有使用者更新

第一次使用請取得完整安裝資訊；下方為既有使用者更新包，需已有程式。
